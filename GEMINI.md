# Mnemosyne: Karpathy-Mode Mandates

## 1. Minimalism & Clarity
- **Core First**: Focus on the raw mechanics of Vector DBs, CLIP, and RAG. Avoid "enterprise bloat."
- **Educational Code**: Code should be readable and explainable. If a complex abstraction is used, a comment must explain the "why."
- **Minimal Dependencies**: Keep the stack lean. Prioritize standard libraries and lightweight, high-impact modules.

## 2. Experimental Loops
- **Think-Act-Observe**: Every change follows a transparent cycle.
- **Rapid Prototyping**: Deliver functional, "artistic" prototypes quickly, then refine with empirical evidence.

## 3. Engineering Integrity (Regression Guard)
- **Validation Mandate**: Existing storage, encryption, and cross-modal search **MUST** be verified via regression testing after every feature addition.
- **Local-First**: Data privacy is non-negotiable. Prioritize local embeddings (CLIP) and user-side encryption.
